# Service Logs Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Extend the existing border-router log viewer to support control service, SCION daemon, and Hummingbird services, accessible via an AS detail DrawerStack.

**Architecture:** Rust `AsInfo` gains a required `daemon: ScionDaemonInfo` field populated by parsing `sd.toml` alongside the existing `hbird.toml` read in `load_project`. The log route param is renamed from `$routerName` to `$serviceName` (no Rust command changes). The AS detail drawer gets a "View Services" button that pushes a services sub-drawer via Mantine `DrawerStack`; the sub-drawer lists control service, daemon, and hummingbird (if present) as TanStack Router `<Link>` elements navigating to the log viewer.

**Tech Stack:** Rust/Tauri 2, specta (TypeScript bindings generation), React 19 + TypeScript, TanStack Router, Mantine 9, `@xyflow/react`
